\begin{abstract}
Este informe presenta el desarrollo de SmartRide Planner, una simulación de planeación de movimiento multiagente sobre una grilla discreta de 20x20. El sistema modela taxis autónomos que deben recoger usuarios con diferentes prioridades, evitando obstáculos y colisiones. Se implementan algoritmos de búsqueda de rutas como A*, Dijkstra, BFS y Greedy Best-First, junto con criterios de asignación basados en cercanía y prioridad.
\end{abstract}
